# Дала тарихы

Қазақстан тарихы бойынша жаттау ойыны (тақырыптық тест 11 және 12): бөлімдер, карточкалар, тест, XP, 16 атақ, жетістіктер, рейтинг.

Сайт: https://arsenchulanov1-code.github.io/Kaztarih-/

## Честный тест

Во время теста (бөлім, қорытынды сынақ, қателерді қайталау) нельзя уходить со страницы.
Если ученик сворачивает браузер, переключает вкладку или приложение, тест начинается заново
с первого вопроса (вопросы перемешиваются), а XP за эту попытку снимается.
Карточки (жаттау) это правило не затрагивает.

## Опыт (XP): одна попытка на уровень

- За каждый уровень (бөлім) и каждый қорытынды сынақ XP даётся только за **первую попытку**. Попытка считается начатой с первого ответа.
- Повторные прохождения обновляют звёзды и лучший результат, но XP не дают. «Қателерді қайталау» тоже без XP. Карточки дают +2 XP один раз за каждую.
- Если во время первой попытки уйти со страницы, тест начинается заново, XP за неё снимается, а право на XP сохраняется.
- Игрокам, которые уже проходили уровни до этого обновления, эти уровни засчитываются как пройденные.

## Последний уровень «Мәтінмен жұмыс»: одна попытка

- Тест можно пройти **один раз**. Во время теста правильность ответов не показывается, итог и разбор — в конце.
- Если уйти со страницы или нажать «×» после первого ответа, тест завершается, неотвеченные вопросы считаются ошибкой, XP не начисляется.
- Для открытия қорытынды сынақ 12 достаточно пройти этот уровень (звезда не нужна).
- **Админ** видит в админ-панели блок «Соңғы деңгей»: кто сдал, сколько правильных (например 4/5), процент, когда. В карточке игрока — ответы по каждому вопросу, число попыток по каждому уровню и где XP уже получен.

Ограничение: проверки работают в браузере. Ученик, который умеет пользоваться консолью разработчика, может изменить свой прогресс; для строгой защиты нужна проверка на сервере (функция Supabase).

## Netlify

Сайт статический, сборка не нужна (`netlify.toml` уже в репозитории).

1. https://app.netlify.com → **Add new site → Import an existing project → GitHub** → выбери `Kaztarih-`.
2. Branch: `main`, Build command: пусто, Publish directory: `.` (подставится из `netlify.toml`) → **Deploy**.
3. Каждый push в `main` обновляет сайт автоматически.

Supabase для входа по логину и паролю дополнительно настраивать не нужно: сайт работает с любого адреса (Netlify, GitHub Pages).

## Общая база данных и рейтинг (Supabase)

Пока `supabase-config.js` пустой, аккаунты и прогресс хранятся только на одном устройстве.
После подключения: вход с любого телефона, **все игроки видят друг друга в рейтинге**, есть админ-панель.
Supabase бесплатный (PostgreSQL), 2‑step verification не нужна.

1. https://supabase.com → **Start your project** → войти через GitHub → **New project** (имя `dala-tarihy`, придумай пароль БД, регион ближайший). Подожди ~2 минуты.
2. **SQL Editor → New query** → вставь всё из `supabase.sql` → **Run**.
3. **Authentication → Sign In / Providers → Email**: выключи **Confirm email** → Save. (Логины превращаются в `логин@dala-tarihy.kz`, письма не приходят, поэтому подтверждение должно быть выключено.)
4. **Project Settings → API**: скопируй **Project URL** и **anon public** key в `supabase-config.js`, commit.
   Эти значения не секретные, защита — правила RLS в `supabase.sql`. Никогда не клади сюда `service_role` key.
5. Зарегистрируйся на сайте — ты в общем рейтинге.

### Как стать админом
После регистрации в **SQL Editor** выполни (подставь свой логин):
```sql
insert into public.admins (uid) select id from auth.users where email = 'твойлогин@dala-tarihy.kz';
```
Дальше других админов можно назначать из админ‑панели.

### Что хранится и кто видит
| Таблица | Что внутри | Кто читает | Кто пишет |
|---|---|---|---|
| `players` | имя, XP, атақ, звёзды, выучено | **все** (рейтинг) | сам игрок или админ |
| `progress` | полный прогресс, ошибки | только сам игрок и админы | сам игрок или админ |
| `admins` | список админов | вошедшие | только админы |

Ограничения: имя до 24 символов, XP до 1 000 000. Чужой результат изменить нельзя.
