# Дала тарихы

Қазақстан тарихы бойынша жаттау ойыны (тақырыптық тест 11 және 12): бөлімдер, карточкалар, тест, XP, 16 атақ, жетістіктер, рейтинг.

Сайт: https://arsenchulanov1-code.github.io/Kaztarih-/

## Ортақ рейтинг (Firebase)
`firebase-config.js` бос болса, аккаунт пен прогресс тек сол құрылғыда сақталады.
Firebase мәндерін қойсаң, аккаунт кез келген телефоннан ашылады және рейтинг бәріне ортақ болады.
Firestore ережелері: `firestore.rules`.
